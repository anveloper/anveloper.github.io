| DPS Store | ^6.0.3    | TypeScript 6 |
| Estimator | ^5.9.3    | TypeScript 5 |

세 레포 모두 `tsconfig.json`의 `strict: true` 확인.

## 3. 추가 반영 항목 (신규 구현분)

### 3.1 DPS

- Jarvis 연동에 **고정 템플릿 디자인 동결(freeze)·해제**와 **삭제된 에디터 템플릿 참조 상품의 자동 재매핑** 추가 (`services/template-freeze`, `services/editor-template`)

### 3.2 DPS Store

- **다면 디자인 미리보기**: 양면·목뒤·어깨처럼 인쇄 면이 여러 개인 디자인의 `previewImage`가 배열로 저장되는데 타입은 `string`이라, 단면(원소 1개)에서만 우연히 동작하던 문제. 정규화 유틸(`parsePreviewImages`)과 순환 표시 컴포넌트로 통일하고 장바구니·주문서·내 주문·작업자·캐셔·관리자·작업지시서 PDF 전 표면에 적용
- **접수 라인 매핑**(`TerminalLineMapping`, 신규 43번째 모델): 주문 단말(키오스크)과 가먼트 PC를 라인으로 묶어 접수 단말 기준으로 출력 장비 배정. 주문 목록·상세에 접수 장비명 표기, 라인별 탭 조회

### 3.3 Estimator

- **상품 타입 확장** 절 신설 — 책자 전제 엔진을 일반 타입 7종으로 확장. 고유 축은 `FinishingOption`에 얹고 포장 방법만 주문당 1회 정액 축으로 분리, 리플렛 접힌 면은 derive로 계산. 어휘(내지↔용지, 권↔매)·코팅 단가 위치·도수 커버리지가 타입마다 갈라지는 지점을 정리한 것이 실제 작업 비용의 대부분이었다는 서술 포함
- 규격 직접입력 치수 **서버 재검증** 추가 (위젯 우회 입력 차단)
- 퀵 절에 배차 접수·취소·상태 동기화와 자체 거리 산정 방식 반영
